# Code of Conduct

## Our standard

Be respectful, constructive, and considerate. Disagreement is welcome; harassment,
discrimination, threats, personal attacks, and the publication of private
information are not.

## Scope

This standard applies in repository discussions, reviews, issues, and other
project spaces, as well as when someone represents the project elsewhere.

## Reporting and enforcement

Report conduct concerns through a private contact method listed on the
[maintainer's GitHub profile](https://github.com/robertsreberski). Do not put
sensitive details in a public issue.

Maintainers will review reports promptly, protect reporters' privacy where
possible, and may edit or remove contributions or restrict participation when
this standard is violated.
