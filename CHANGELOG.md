# Changelog

## Unreleased

This repository is the source-only mono-agent successor preview. It contains
the config-first 23-package architecture described in
[`docs/reference/architecture.md`](./docs/reference/architecture.md).

No package has been published from this repository. Existing registry
artifacts under the same package names and versions belong to the predecessor
repository, not this source; do not install or execute them.

Current source-preview changes are reviewed through pull requests and the
repository gates. The first released version will receive a dated entry only
after an explicitly authorized lockstep publication and clean registry
verification.

Predecessor release history is intentionally not copied into this successor
changelog.
